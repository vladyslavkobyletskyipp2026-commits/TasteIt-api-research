Дослідження API для проєкту TasteIt

Обране джерело даних: TheMealDB API ( TheMealDB.com)
Статус: протестовано на прототипі, логіку підключення передано в основний проєкт.

Чому зупинилися на TheMealDB
Перевірив кілька безкоштовних баз з рецептами (зокрема Spoonacular), але там бракувало потрібних даних або посилань. Spoonacular закриває всі наші потреби в одному запиті:
- підтягує якісні фотографії страв та відеоінструкції;
- має нормальну розбивку рецепту на кроки (analyzedInstructions) і показує час приготування;
- повертає окремий список інгредієнтів з кількістю, одиницями виміру та даними для пошуку продуктів.

Приклади запитів, які тестувалися

1. Пошук страв із базовою інформацією:
GET https://themealdb.com

2. Отримання повної інформації про конкретну страву за її ID:
GET https://themealdb.com{id}

Основні поля, які беремо з відповіді API для картки:
- title: назва страви
- image: посилання на картинку
- readyInMinutes: скільки часу готувати
- extendedIngredients: масив інгредієнтів та їх грамівка
- analyzedInstructions: покроковий рецепт
- sourceUrl: посилання на першоджерело рецепту
